# 데이터셋 영상 vs 시뮬 카메라 진단 (2026-09-26, 설정 변경 없음)

대상: `igris_c_trainer.zip`의 `sample_dataset`(10 에피소드, 2,467 프레임, 20 fps; `cam_head` 1280×480 좌|우, `cam_left`/`cam_right` 640×480; 작업 "Pick up the bottle / melamine cup") vs 현재 IGRIS 시뮬 카메라(공식 robot_cfg.py 기반: 머리 640×480 fx 433.3, 손 320×200 LEFT/RIGHT_WRIST_INTRINSIC + 학습용 640×480 `train_extend`).
로컬 사본: `/mnt/isaac/reference/igris_c_trainer/`(zip에서 추출), 추출 프레임 `frames/`, 대표 자세 `representative_poses.json`.

## 방법
- 대표 자세 15개: 에피소드 0·2·4·5·8 × {start, left_arm_forward(왼어깨 pitch 최소), left_grip_closed(왼검지 최대)}.
- `observation.state` 23채널 중 팔 14 + 허리 3 = 17채널을 시뮬 관절에 매핑해(`left_shoulder_pitch.pos` → `Joint_Shoulder_Pitch_Left` 등, 부호 변환 없음) `--pose-file`로 재현 촬영(진단 전용 옵션; YAML 기본값 불변). 왼손 손가락 6채널은 시뮬 손가락 22 DOF와 대응이 없어 미적용(시뮬 손가락 펴짐). PD 정착 오차 최대 0.095 rad.
- 머리는 현재 기본 30°와 진단용 0°(`--head-pitch 0`, 이번 실행에만) 두 벌 촬영. 데이터셋에는 목 관절 상태가 없다.
- 비교는 **원본 카메라 프레임**끼리(모니터의 손 ±90° 회전은 표시 전용이며 여기서는 적용하지 않음). 나란히 저장: `data/isaac/dataset_compare/<ep>_<label>_f<idx>_{head,hands}.png`(30장), 축소본 `docs/img/dataset_compare/`.
- 픽셀 차·색상은 배경이 달라 비교 근거로 쓰지 않았다. 실기 내부 파라미터·왜곡·장착 각도는 데이터셋에 없으므로 해당 항목은 **미확인**.

## 관찰 요약
| 카메라 | 데이터셋 | 시뮬(현재) |
| --- | --- | --- |

| 오른손 | 시작 자세에서 **바닥과 로봇 발**(카메라가 아래로 향함), 넓은 화각, 영상이 90° 회전된 듯한 구도 | 자기 손·손가락 셸이 화면 대부분(평균 자기 메시 40%, 깊이 중앙값 0.04 m), 작업대 트레이 일부 |

## 수정 우선순위
1. **손 카메라 방향(#5, #6)** — 현재 시뮬 손 영상은 자기 손을 보고 있어 학습 입력으로 무의미. 가장 먼저 해결.
2. **로봇–작업대 거리·소품 배치(#3)** — 머리 영상의 작업 공간 위치/크기 차이의 주원인.
3. **머리 화각/왜곡(#1)** — 실기 내부 파라미터 확보 필요(문의 또는 캘리브레이션). 확보 전엔 추정만.
4. 목 pitch(#2), 스테레오 기하(#4) — #1 확정 후.
5. 손 내부 파라미터(#7), 손가락 매핑(#9), 외형·배경(#8).

## 한 번에 한 변수씩 검증하는 튜닝 순서
각 단계는 `--pose-file /mnt/isaac/reference/igris_c_trainer/representative_poses.json`으로 같은 15자세를 재촬영해 `data/isaac/dataset_compare/`와 대조한다.
1. 손목 3관절을 0으로 둔 단일 자세에서 시뮬 손 카메라 광축 방향을 기록(기준선).
2. 왼손 카메라 `rot`만 광축 기준 90°씩 회전(0/90/180/270) → 데이터셋 시작 자세(천장)와 팔 전방 자세(원경)를 재현하는 각도 선택. 오른손 동일.
3. 그래도 자기 손 가림이 크면 `axial_offset_m`만 +10→+20 mm.
4. 손목 yaw·roll 부호를 한 관절씩 반전해 데이터셋 자세 재현이 좋아지는지 확인(3관절 부호 조합은 관절별로).
5. 로봇 위치만 y −0.3 m(작업대에서 후퇴) → 머리 영상의 작업대 모서리 행 비교.
6. 소품(상자·병 대체 프리미티브)만 작업대 중앙에 추가.
7. 실기 머리 내부 파라미터 확보 → head `intrinsic`/`distortion`만 교체 → 지평선·모서리 행 재비교.
8. 목 pitch만 15/20/25/30° 스윕.
9. 스테레오 베이스라인·수렴각(#4)은 실측값이 있을 때만.
